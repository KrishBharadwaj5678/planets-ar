## <img src="https://github.com/KrishBharadwaj5678/planets-ar/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/planets-ar.git
````

### 2️⃣ Переход в папку проекта

```bash
cd planets-ar
```

### 3️⃣ Добавление проекта в Unity Hub

- Откройте **Unity Hub**, выберите **Add** и укажите клонированную папку **planets-ar**

### 4️⃣ Открытие проекта

- После завершения импорта файлов Unity откройте основную сцену из папки **Assets**

### 5️⃣ Запуск проекта

- Нажмите кнопку **Play** в Unity Editor, чтобы запустить Planets AR

## <img src="https://github.com/KrishBharadwaj5678/planets-ar/raw/main/readme/gifs/howItWorks.gif" width="35"/> Как это работает

1️⃣ Откройте Planets AR и разрешите доступ к камере для AR.

2️⃣ Выберите планету, которую хотите разместить в окружающем пространстве.

3️⃣ Просканируйте окружающее пространство с помощью камеры.

4️⃣ Выбранная планета автоматически появится в вашей окружающей среде.
