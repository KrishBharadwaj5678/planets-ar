<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/planets-ar/raw/main/Assets/Assets/Assets/Logo.png" width="40"/> Planets AR</h1>

<p align="center">
  Planets ARは、没入感のある3D惑星を拡張現実（AR）で体験し、太陽系を身近に感じられるアプリです。
</p>

## <img src="https://github.com/KrishBharadwaj5678/planets-ar/raw/main/readme/gifs/features.gif" width="35"/> 機能

| 機能 | 説明 |
| --- | --- |
| 🪐 **ARで惑星を探索** | 没入感のある3Dモデルで太陽系を拡張現実として体験できます |
| 🎵 **BGM** | 太陽系を探索しながら臨場感のあるBGMを楽しめます |
| 🔇 **BGMのミュート / ミュート解除** | BGMを簡単にミュートまたはミュート解除できます |
| 🔊 **音声ナレーション** | 各惑星について詳しく説明する音声ナレーションを聞くことができます |
| ▶️ **再生 / 一時停止 / リセット** | ナレーションを再生、一時停止、または最初から再生できます |

## <img src="https://github.com/KrishBharadwaj5678/planets-ar/raw/main/readme/gifs/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/planets-ar.git
````

### 2️⃣ プロジェクトフォルダへ移動

```bash
cd planets-ar
```

### 3️⃣ Unity Hubに追加

- **Unity Hub**を開き、**Add**を選択して、クローンした**planets-ar**フォルダを指定します。

### 4️⃣ プロジェクトを開く

- Unityによるプロジェクトファイルのインポートが完了したら、**Assets**フォルダからメインシーンを開きます。

### 5️⃣ プロジェクトを実行

- Unity Editorの**Play**ボタンを押してPlanets ARを起動します。

<img src="https://github.com/KrishBharadwaj5678/planets-ar/raw/main/readme/gifs/divider.gif" width="100%"/> 

## <img src="https://github.com/KrishBharadwaj5678/planets-ar/raw/main/readme/gifs/howItWorks.gif" width="35"/> 使い方

1️⃣ **Planets AR**を起動し、AR機能を使用するためにカメラへのアクセスを許可します。

2️⃣ 表示された惑星の中から、探索したい惑星を選択します。

3️⃣ カメラを使って周囲の空間をスキャンします。

4️⃣ 選択した惑星が周囲の空間に自動的に表示されます。
