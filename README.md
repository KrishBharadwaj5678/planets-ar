## <img src="https://github.com/KrishBharadwaj5678/planets-ar/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/KrishBharadwaj5678/planets-ar.git
```

### 2️⃣ Navigate to the Project

```bash
cd planets-ar
```

### 3️⃣ Add to Unity Hub

- Open **Unity Hub**, select **Add**, and choose the cloned **planets-ar** folder

### 4️⃣ Open the Project

- Once Unity finishes importing the project files, open the main scene from the **Assets** folder

### 5️⃣ Run the Project

- Press the **Play** button in Unity Editor to launch Planets AR

## <img src="https://github.com/KrishBharadwaj5678/planets-ar/raw/main/readme/gifs/howItWorks.gif" width="35"/> How It Works 

1️⃣ Open **Planets AR** and grant camera permissions for AR functionality.

2️⃣ Choose a planet to bring into your environment.

3️⃣ Scan your surroundings.

4️⃣ The selected planet will automatically render in your environment.
