## <img src="https://github.com/KrishBharadwaj5678/planets-ar/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Primeiros Passos

### 1️⃣ Clonar o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/planets-ar.git
````

### 2️⃣ Aceder à Pasta do Projeto

```bash
cd planets-ar
```

### 3️⃣ Adicionar ao Unity Hub

- Abra o **Unity Hub**, selecione **Add** e escolha a pasta **planets-ar** clonada.

### 4️⃣ Abrir o Projeto

- Depois de o Unity terminar de importar os ficheiros do projeto, abra a cena principal a partir da pasta **Assets**.

### 5️⃣ Executar o Projeto

- Prima o botão **Play** no Unity Editor para iniciar o Planets AR.

<img src="https://github.com/KrishBharadwaj5678/planets-ar/raw/main/readme/gifs/divider.gif" width="100%"/> 

## <img src="https://github.com/KrishBharadwaj5678/planets-ar/raw/main/readme/gifs/howItWorks.gif" width="35"/> Como Funciona

1️⃣ Abra o **Planets AR** e permita o acesso à câmara para usar a realidade aumentada.

2️⃣ Escolha o planeta que pretende explorar.

3️⃣ Digitalize o ambiente à sua volta utilizando a câmara.

4️⃣ O planeta selecionado será automaticamente apresentado no seu ambiente.
